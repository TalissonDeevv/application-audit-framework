# Architecture Auditor

## Overview

The Architecture Auditor is responsible for evaluating the structural design of a software project.

It analyzes how the application is organized, how components communicate, and whether the architecture follows engineering best practices.

This auditor consumes the project inventory generated by the Discovery Auditor.

---

# Purpose

The purpose of the Architecture Auditor is to assess whether the system architecture is maintainable, scalable, modular, and aligned with software engineering principles.

---

# Responsibilities

The Architecture Auditor evaluates:

- Project structure
- Layer separation
- Module organization
- Component responsibilities
- Dependency relationships
- Architectural patterns
- Coupling and cohesion
- Scalability
- Maintainability
- Domain organization

---

# Out of Scope

The Architecture Auditor does not:

- Detect security vulnerabilities
- Measure runtime performance
- Review infrastructure
- Analyze dependency vulnerabilities
- Produce performance recommendations

---

# Inputs

- Discovery project inventory
- Source code
- Project structure
- Configuration files

---

# Outputs

The Architecture Auditor produces:

- Architecture findings
- Structural observations
- Engineering recommendations
- Architecture score

---

# Consumers

Its output is consumed by:

- Report Auditor
- Security Auditor
- Performance Auditor
