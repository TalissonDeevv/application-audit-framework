# Architecture Specification

## Objective

Evaluate the software architecture using engineering principles and best practices.

---

# Input

- Discovery inventory
- Repository structure
- Source code
- Configuration files

---

# Analysis Process

The auditor must:

1. Understand the project structure.
2. Identify architectural patterns.
3. Evaluate module organization.
4. Detect dependency relationships.
5. Evaluate maintainability.
6. Identify architectural risks.
7. Generate findings.

---

# Expected Output

The output should include:

- Architecture summary
- Findings
- Recommendations
- Overall architecture score

---

# Completion Criteria

The Architecture Auditor is complete when:

- Architecture has been analyzed.
- Findings have been documented.
- Recommendations have been generated.
- Architecture score has been calculated.

---

# Limitations

The Architecture Auditor must never:

- Analyze security vulnerabilities.
- Analyze runtime performance.
- Suggest implementation code.
