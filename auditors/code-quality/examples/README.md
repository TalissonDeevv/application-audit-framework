# Code Quality Auditor Examples

## Overview

This directory contains practical examples demonstrating how the Code Quality Auditor evaluates software quality issues.

Examples are used to validate the auditor's ability to identify maintainability problems, code smells and engineering quality issues.

---

## Purpose

Examples help demonstrate:

- Expected findings
- Evidence collection
- Severity classification
- Recommendations
- Audit report generation

---

## Example Structure

Each example should contain:

```
example-name/

├── source/
│   └── application code

├── context.md

├── expected-findings.md

└── report.md
```

---

## Example Categories

### Poor Code Quality

Examples containing:

- High complexity
- Duplicate code
- Poor naming
- Bad architecture
- Missing tests
- Poor error handling

---

### Good Code Quality

Examples demonstrating:

- Clean architecture
- Good modularity
- Proper naming
- Effective testing
- Maintainable design

---

## Finding Validation

Each example should define:

- Finding title
- Description
- Evidence
- Severity
- Expected recommendation

---

## Guidelines

Examples should:

- Be realistic
- Contain clear problems
- Avoid unnecessary complexity
- Represent real development scenarios
