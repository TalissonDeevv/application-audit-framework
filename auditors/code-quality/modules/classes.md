# Classes Module

## Overview

Evaluates object-oriented design and class organization.

---

## Objective

Identify classes that violate maintainability and object-oriented principles.

---

## What to Inspect

Inspect:

- Class size
- Responsibilities
- Dependencies
- Cohesion
- Coupling
- Encapsulation

---

## Common Findings

- God Classes
- Multiple responsibilities
- Excessive dependencies
- Low cohesion
- Tight coupling
- Poor encapsulation

---

## Severity

High when class design impacts maintainability.

Medium for structural improvements.

Low for cosmetic improvements.

---

## Expected Evidence

- Large classes
- High dependency count
- Mixed responsibilities
- Public mutable state

---

## Recommendations

Split responsibilities.

Increase cohesion.

Reduce coupling.

Apply SOLID principles.

---

## References

- SOLID
