# Complexity Module

## Overview

Evaluates the complexity of the source code.

---

## Objective

Detect code that is unnecessarily difficult to understand or maintain.

---

## What to Inspect

Inspect:

- Cyclomatic complexity
- Nested conditions
- Deep loops
- Long methods
- Large switch statements
- Excessive branching

---

## Common Findings

- High complexity
- Deep nesting
- Long decision trees
- Complex business logic

---

## Severity

High for extremely complex code.

Medium for maintainability issues.

Low for optimization opportunities.

---

## Expected Evidence

- Large methods
- Nested blocks
- Conditional chains

---

## Recommendations

Split responsibilities.

Extract methods.

Simplify logic.

Reduce branching.
