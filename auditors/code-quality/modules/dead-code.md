# Dead Code Module

## Overview

Detects unused, unreachable or obsolete code within the project.

Dead code increases complexity and maintenance cost.

---

## Objective

Identify code that no longer contributes to the application.

---

## What to Inspect

Inspect:

- Unused functions
- Unused classes
- Unused variables
- Unreachable branches
- Deprecated modules
- Disabled code blocks
- Unused dependencies

---

## Common Findings

- Commented-out code
- Unused files
- Unused imports
- Deprecated implementations
- Unreachable conditions

---

## Severity

Medium when dead code increases complexity.

Low when impact is minimal.

High when obsolete code creates security or operational risks.

---

## Expected Evidence

- Unused references
- Static analysis results
- Import analysis
- Repository history

---

## Recommendations

Remove unused code.

Clean deprecated implementations.

Avoid keeping disabled code.

Maintain a clean codebase.
