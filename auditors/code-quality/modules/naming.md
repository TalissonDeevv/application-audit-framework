# Naming Module

## Overview

Evaluates the quality and consistency of naming across the project.

Clear and meaningful names improve readability, maintainability and communication between developers.

---

## Objective

Identify poor naming conventions that reduce code clarity.

---

## What to Inspect

Inspect:

- Variable names
- Function names
- Class names
- Interface names
- Enum names
- Constant names
- File names
- Folder names

---

## Common Findings

- Generic names
- Ambiguous names
- Misleading names
- Inconsistent naming conventions
- Abbreviations without meaning
- Single-letter variables outside acceptable contexts

---

## Severity

High when naming causes misunderstanding.

Medium when consistency is affected.

Low for cosmetic improvements.

---

## Expected Evidence

- Poorly named variables
- Generic classes
- Misleading functions
- Inconsistent conventions

---

## Recommendations

Use descriptive names.

Follow project naming conventions.

Avoid unnecessary abbreviations.

Prefer clarity over brevity.
