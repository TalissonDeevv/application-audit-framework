# Readability Module

## Overview

Evaluates whether the code is easy for developers to understand.

Readable code improves collaboration, debugging and future maintenance.

---

## Objective

Identify code patterns that reduce human understanding.

---

## What to Inspect

Inspect:

- Code formatting
- Naming clarity
- Function structure
- Comments
- Variable usage
- Logical flow
- Consistency

---

## Common Findings

- Confusing logic
- Poor naming
- Excessive comments
- Complex expressions
- Inconsistent formatting
- Difficult-to-follow flows

---

## Severity

High when readability prevents safe changes.

Medium when understanding requires excessive effort.

Low for minor improvements.

---

## Expected Evidence

- Source code examples
- Naming patterns
- Complex expressions
- Formatting inconsistencies

---

## Recommendations

Use meaningful names.

Simplify expressions.

Keep functions focused.

Maintain consistent formatting.

Write code for humans first.
