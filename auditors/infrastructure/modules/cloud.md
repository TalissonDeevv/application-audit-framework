# Cloud Infrastructure Module

## Overview

Evaluates cloud infrastructure organization, configuration and operational maturity.

Cloud environments require proper resource management, security controls and scalability planning.

---

## Objective

Identify cloud configuration issues that affect reliability, security and cost efficiency.

---

## What to Inspect

Inspect:

- Cloud resources
- Resource organization
- Permissions
- Scaling configuration
- Cost management
- Availability settings
- Infrastructure automation

---

## Common Findings

- Unmanaged resources
- Excessive permissions
- Missing backups
- Poor cost control
- Manual infrastructure changes
- Lack of scalability planning

---

## Operational Impact

Possible impacts:

- Increased costs
- Security exposure
- Availability issues
- Difficult maintenance

---

## Severity

Critical:

When cloud configuration threatens system availability or security.

High:

When significant operational risks exist.

Medium:

When improvements increase maturity.

Low:

For optimization opportunities.

---

## Expected Evidence

- Cloud configuration
- Infrastructure as Code
- Resource policies
- Deployment files

---

## Recommendations

Document cloud resources.

Apply least privilege.

Automate infrastructure.

Monitor costs.

Plan scalability.
