# Monitoring Module

## Overview

Evaluates the application's monitoring strategy, observability and operational visibility.

A mature monitoring system allows teams to detect, diagnose and respond to incidents quickly.

---

## Objective

Identify missing or insufficient monitoring capabilities that reduce operational awareness.

---

## What to Inspect

Inspect:

- Metrics collection
- Health checks
- Alerting
- Dashboards
- Service monitoring
- Infrastructure monitoring
- Application monitoring
- Uptime monitoring
- Distributed tracing
- Observability platforms

---

## Common Findings

- Missing monitoring
- No health endpoints
- Missing alerts
- Incomplete metrics
- Poor observability
- No tracing
- No uptime monitoring

---

## Operational Impact

Possible impacts:

- Slow incident response
- Undetected failures
- Reduced availability
- Difficult troubleshooting

---

## Severity

Critical:

Production systems without monitoring.

High:

Important components are not monitored.

Medium:

Monitoring coverage is incomplete.

Low:

Optimization opportunities.

---

## Expected Evidence

- Monitoring configuration
- Dashboards
- Alert rules
- Metrics endpoints
- Infrastructure configuration

---

## Recommendations

Monitor all critical services.

Implement health endpoints.

Collect infrastructure metrics.

Create actionable alerts.

Adopt centralized observability.
