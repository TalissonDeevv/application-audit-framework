# Servers Module

## Overview

Evaluates server configuration, management and operational practices.

Poor server management can introduce security, reliability and performance problems.

---

## Objective

Identify server-level issues affecting application operation.

---

## What to Inspect

Inspect:

- Operating system configuration
- Resource allocation
- Server updates
- User permissions
- Services running
- Firewall configuration
- System hardening

---

## Common Findings

- Outdated operating systems
- Excessive privileges
- Missing security updates
- Unnecessary services running
- Poor resource allocation

---

## Operational Impact

Possible impacts:

- Security vulnerabilities
- Service instability
- Resource waste
- Maintenance difficulty

---

## Severity

High:

When server configuration creates security or availability risks.

Medium:

When operational improvements are needed.

Low:

For optimization recommendations.

---

## Expected Evidence

- Server configuration
- OS information
- Access policies
- Monitoring data

---

## Recommendations

Keep systems updated.

Apply least privilege.

Remove unnecessary services.

Monitor resource usage.

Harden server configuration.
