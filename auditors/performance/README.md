# Performance Auditor

## Overview

The Performance Auditor evaluates the efficiency, responsiveness and scalability of a software system.

Its objective is to identify performance bottlenecks, inefficient implementations and architectural decisions that negatively impact application speed and resource consumption.

---

## Objectives

The auditor evaluates:

- Execution efficiency
- Resource consumption
- Response times
- Database performance
- Frontend performance
- Scalability
- Network efficiency
- Memory usage

---

## Audit Areas

The Performance Auditor is divided into specialized modules:

- Algorithms
- Complexity
- Database
- Queries
- Caching
- Memory
- CPU
- Concurrency
- Async Processing
- Network
- APIs
- Frontend
- Bundle Size
- Rendering
- Assets
- Lazy Loading
- Compression
- Scalability
- Bottlenecks

---

## Expected Output

Each finding must contain:

- Title
- Description
- Evidence
- Impact
- Recommendation
- Severity
- Confidence
- References

All findings must follow the Finding Schema.

---

## Scope

This auditor applies to:

- Web applications
- APIs
- Backend systems
- Frontend applications
- Mobile backends
- Cloud applications
- Distributed systems
