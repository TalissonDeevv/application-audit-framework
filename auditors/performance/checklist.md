# Performance Checklist

## Algorithms

- Algorithms have appropriate complexity.
- Expensive operations are optimized.
- Unnecessary calculations are avoided.

---

## Database

- Queries are optimized.
- Indexes are considered.
- N+1 problems are avoided.
- Connections are managed properly.

---

## Memory

- No obvious memory leaks.
- Resources are released.
- Large objects are handled efficiently.

---

## CPU

- Heavy computations are optimized.
- Blocking operations are minimized.
- Expensive loops are reviewed.

---

## APIs

- Response payloads are reasonable.
- Pagination is implemented when necessary.
- Expensive operations are controlled.

---

## Caching

- Cache opportunities are identified.
- Cache invalidation is considered.
- Unnecessary repeated operations are avoided.

---

## Frontend

- Bundle size is controlled.
- Rendering is optimized.
- Assets are optimized.
- Lazy loading is used when appropriate.

---

## Network

- Requests are minimized.
- Compression is considered.
- Data transfer is optimized.

---

## Scalability

- Application can handle growth.
- Bottlenecks are identified.
- Resource usage is predictable.

---

## General

- Performance issues have evidence.
- Recommendations are practical.
- Findings are prioritized correctly.
