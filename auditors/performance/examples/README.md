# Performance Auditor Examples

## Overview

This directory contains practical examples demonstrating how the Performance Auditor evaluates application performance issues.

Examples are used to validate the auditor's ability to identify bottlenecks, inefficient implementations and scalability concerns.

---

## Purpose

Examples demonstrate:

- Performance findings
- Evidence identification
- Impact analysis
- Severity classification
- Recommended improvements

---

## Example Structure

Each example should contain:

```
example-name/

├── source/
│   └── application code

├── context.md

├── expected-findings.md

└── report.md
```

## Finding Validation

Each example should define:

- Finding title
- Description
- Evidence
- Performance impact
- Severity
- Expected recommendation

---

## Guidelines

Examples should:

- Represent realistic scenarios
- Have measurable performance concerns when possible
- Avoid artificial complexity
- Demonstrate practical engineering problems
