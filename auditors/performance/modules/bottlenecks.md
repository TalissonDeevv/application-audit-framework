# Bottlenecks Performance Module

## Overview

Identifies the main constraints limiting system performance.

A bottleneck is any component that restricts overall system efficiency.

---

## Objective

Find critical performance limitations and prioritize optimization efforts.

---

## What to Inspect

Inspect:

- CPU usage
- Memory usage
- Database operations
- Network communication
- External services
- Application logic
- Infrastructure limitations

---

## Common Findings

- Slow database operations
- Expensive algorithms
- Blocking processes
- External service dependency
- Resource exhaustion
- Inefficient architecture decisions

---

## Performance Impact

Possible impacts:

- Increased latency
- Reduced throughput
- Poor user experience
- System instability

---

## Severity

Critical:

When the bottleneck threatens availability or scalability.

High:

When performance degradation is significant.

Medium:

When optimization is recommended.

Low:

When impact is limited.

---

## Expected Evidence

- Source code
- Architecture
- Metrics (when available)
- Logs
- Configuration

---

## Recommendations

Prioritize highest-impact problems.

Measure before optimizing.

Remove limiting factors.

Improve resource utilization.

Validate improvements after changes.
