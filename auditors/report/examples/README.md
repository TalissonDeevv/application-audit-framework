# Report Auditor Examples

## Overview

This directory contains practical examples of reports generated by the AI Audit Framework (AAF).

The examples demonstrate how findings from different auditors are consolidated into a professional, consistent and actionable audit report.

---

# Purpose

Examples are intended to:

- Demonstrate report structure
- Validate report generation
- Showcase reporting best practices
- Verify consistency between sections
- Serve as reference implementations

---

# Example Structure

Each example should follow this structure:

```
example-name/

├── findings/
│   ├── discovery.json
│   ├── architecture.json
│   ├── security.json
│   ├── code-quality.json
│   ├── performance.json
│   └── infrastructure.json
│
├── generated-report.md
│
├── executive-summary.md
│
├── technical-summary.md
│
└── metadata.json
```
