# Compliance Module

## Overview

Evaluates whether the audited project follows recognized engineering, security and software development standards.

Compliance helps organizations measure adherence to industry best practices.

---

## Objective

Summarize compliance status using supported frameworks.

---

## Responsibilities

The module must:

- Map findings to standards.
- Identify compliance gaps.
- Highlight compliant practices.
- Preserve traceability.

---

## Supported Standards

Examples include:

- OWASP Top 10
- OWASP ASVS
- CWE
- CVSS
- NIST SSDF
- CIS Controls

Additional standards may be added in future versions.

---

## Compliance Categories

Evaluate:

- Security
- Architecture
- Infrastructure
- Development Practices
- Code Quality

---

## Validation

Compliance analysis must:

- Be evidence-based.
- Never infer unsupported compliance.
- Clearly identify gaps.

---
