# Report Module Template

## Overview

This module defines how a specific section of the audit report should be generated.

Each Report Module is responsible for producing one standardized section of the final report.

---

## Objective

Describe the purpose of this report section.

---

## Inputs

This module may consume:

- Findings
- Evidence
- Severity
- Confidence
- Metrics
- Project metadata

---

## Responsibilities

The module must:

- Organize information clearly.
- Preserve evidence.
- Maintain consistency.
- Avoid duplicated content.
- Produce actionable information.

---

## Output

The generated section should include:

- Title
- Description
- Structured content
- Supporting references (when applicable)

---

## Validation Rules

The generated section must:

- Be technically accurate.
- Be concise.
- Follow the Report Schema.
- Be consistent with other sections.

---

## Constraints

The module must never:

- Invent information.
- Remove valid findings.
- Change evidence.
- Contradict previous sections.
