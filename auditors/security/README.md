# Security Auditor

## Overview

The Security Auditor is the security analysis engine of the AI Audit Framework (AAF).

It performs comprehensive, evidence-based security assessments across the entire application stack.

Unlike generic AI prompts, the Security Auditor follows a structured methodology, standardized rules, and internationally recognized security references.

Every analysis is based on observable evidence extracted from the project.

---

## Mission

Protect software by identifying vulnerabilities before they become incidents.

---

## Objectives

The Security Auditor aims to:

- Identify security vulnerabilities.
- Detect insecure coding practices.
- Review authentication and authorization.
- Validate session management.
- Analyze input validation.
- Detect injection vulnerabilities.
- Review application configuration.
- Evaluate dependency security.
- Assess production security readiness.

---

## Supported Standards

The Security Auditor follows recognized security standards, including:

- OWASP Top 10
- OWASP ASVS
- OWASP Cheat Sheets
- CWE
- CVSS
- NIST Secure Software Development Framework

---

## Modules

The Security Auditor is composed of specialized modules.

Each module focuses on one security domain.

- Authentication
- Authorization
- Session Management
- JWT
- Secrets Management
- Input Validation
- SQL Injection
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Insecure Direct Object References (IDOR)
- Server-Side Request Forgery (SSRF)
- CORS
- Security Headers
- File Upload
- Rate Limiting
- Logging
- Dependency Analysis
- Environment Configuration

---

## Inputs

- Discovery Inventory
- Architecture Report

- Dependency Manifests
- Environment Configuration

## Outputs

The Security Auditor produces:

- Security Findings
- Risk Classification
- Severity Assessment
- Engineering Recommendations
- Security Score
- Executive Summary

---

## Principles

The Security Auditor follows these principles:

- Evidence over assumptions
- Security before convenience
- Explain every finding
- Never invent vulnerabilities
- Clearly communicate uncertainty
