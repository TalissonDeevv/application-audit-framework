# Security Examples

This directory contains example security audits generated using the AI Audit Framework.

## Purpose

The examples demonstrate how the Security Auditor behaves when auditing different technologies and architectures.

Each example includes:

- Project Overview
- Technologies Detected
- Security Findings
- Severity Classification
- Confidence Level
- Evidence
- Recommendations
- Security Score

## Planned Examples

- React + Express
- Next.js + Prisma
- NestJS
- Spring Boot
- Laravel
- ASP.NET Core
- Django
- FastAPI

## Goals

- Validate the Security Auditor
- Demonstrate report quality
- Provide benchmark projects
- Help contributors understand expected outputs
