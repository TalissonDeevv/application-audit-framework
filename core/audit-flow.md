# Audit Flow

## Purpose

This document defines the official execution flow of the AI Audit Framework (AAF).

Every auditor must follow this workflow.

---

# Audit Lifecycle

1. Project Discovery
2. Architecture Analysis
3. Technology Detection
4. Security Audit
5. Code Quality Audit
6. Performance Audit
7. Infrastructure Audit
8. Finding Aggregation
9. Risk Assessment
10. Score Calculation
11. Report Generation

---

# Workflow

Discovery
↓

Architecture
↓

Security
↓

Code Quality
↓

Performance
↓

Infrastructure
↓

Aggregate Findings
↓

Calculate Risk
↓

Generate Report

---

# Execution Rules

- Each stage must complete before the next begins.
- Findings must include evidence.
- Unsupported assumptions are prohibited.
- Every finding must reference its originating module.
- Duplicate findings should be merged.
- Findings must follow the Finding Schema.

---

# Output

The final output consists of:

- Project Summary
- Technology Stack
- Findings
- Risk Score
- Security Score
- Overall Grade
- Recommendations
- Final Report
