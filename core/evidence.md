# Evidence Requirements

## Purpose

Every finding generated by the framework must be supported by evidence.

---

Required Fields

- Title
- Description
- Severity
- Confidence
- Evidence
- Impact
- Recommendation
- References

---

Evidence Types

- Source Code
- Configuration
- API Response
- HTTP Headers
- Logs
- Build Files
- Infrastructure
- Dependency Metadata

---

Rules

Never report vulnerabilities without evidence.

If evidence is insufficient:

Classify as Potential Risk.

Never fabricate evidence.

Evidence should be reproducible whenever possible.
