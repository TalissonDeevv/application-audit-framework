# Reporting Standard

## Purpose

Defines the standard report structure generated by the framework.

---

Sections

1. Executive Summary

2. Project Information

3. Technology Stack

4. Architecture Overview

5. Security Findings

6. Code Quality Findings

7. Performance Findings

8. Infrastructure Findings

9. Risk Assessment

10. Overall Score

11. Recommendations

12. Conclusion

---

Formatting Rules

Every finding must include:

- Severity
- Confidence
- Evidence
- Recommendation

---

Report Types

- Executive Report
- Technical Report
- Full Audit Report

---

Output Formats

- Markdown
- HTML
- PDF
- JSON
