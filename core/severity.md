# Severity Levels

## Purpose

Defines the severity classification used by every auditor.

---

Critical

Immediate compromise of confidentiality, integrity or availability.

Examples

- SQL Injection
- Remote Code Execution
- Authentication bypass

---

High

Serious vulnerability requiring prompt remediation.

Examples

- IDOR
- Weak authentication
- Privilege escalation

---

Medium

Security weakness requiring specific conditions.

Examples

- Weak validation
- Missing headers
- Long session expiration

---

Low

Minor issue.

Examples

- Missing security best practices
- Weak configuration

---

Informational

Observation or recommendation.

Examples

- Code improvement
- Architecture suggestion
