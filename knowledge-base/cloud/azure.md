# Microsoft Azure Audit Profile

## Overview

Microsoft Azure is a cloud platform for enterprise applications and services.

---

## Detection

Typical indicators:

- Azure SDK
- Azure CLI
- ARM Templates
- Bicep
- Azure Functions
- App Service

---

## Security Focus

Inspect:

- Azure AD
- Managed Identity
- Key Vault
- RBAC
- Network Security Groups
- Encryption

---

## Infrastructure Focus

Inspect:

- Virtual Networks
- App Services
- Virtual Machines
- Storage Accounts
- Load Balancers

---

## Performance Focus

Inspect:

- Autoscaling
- Monitoring
- Resource allocation
- Database performance

---

## Common Findings

- Weak RBAC
- Secrets in configuration
- Public storage accounts
- Missing monitoring
- Excessive permissions

---

## Recommended Practices

- Managed Identity
- Azure Key Vault
- RBAC
- Azure Monitor
- Defender for Cloud
