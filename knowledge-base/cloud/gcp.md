# Google Cloud Platform Audit Profile

## Overview

Google Cloud Platform (GCP) provides scalable cloud infrastructure and managed services.

---

## Detection

Typical indicators:

- Google Cloud SDK
- Cloud Run
- Cloud Functions
- Compute Engine
- GKE
- Cloud SQL

---

## Security Focus

Inspect:

- IAM permissions
- Service Accounts
- Secret Manager
- Public resources
- Encryption
- Firewall rules

---

## Infrastructure Focus

Inspect:

- Compute resources
- Networking
- Kubernetes
- Managed databases
- Storage

---

## Performance Focus

Inspect:

- Autoscaling
- CDN
- Caching
- Monitoring
- Resource optimization

---

## Common Findings

- Overprivileged service accounts
- Public buckets
- Missing encryption
- Weak firewall rules
- Secrets in source code

---

## Recommended Practices

- Principle of Least Privilege
- Secret Manager
- Cloud Monitoring
- Automatic Backups
- IAM Best Practices
