# ASP.NET Core Audit Profile

## Overview

ASP.NET Core is Microsoft's modern framework for building web applications and APIs.

---

## Security Focus

Inspect:

- Identity
- Authorization Policies
- JWT
- Data Protection
- HTTPS
- Secrets

---

## Architecture

Inspect:

- Controllers
- Minimal APIs
- Services
- Dependency Injection
- Middleware

---

## Performance

Inspect:

- Async APIs
- Caching
- EF Core
- Connection Pooling

---

## Common Findings

- Missing authorization policies
- Weak JWT validation
- Blocking operations

---

## Recommended Practices

- ASP.NET Identity
- FluentValidation
- Minimal APIs (when appropriate)
- Health Checks
