# Express Audit Profile

## Overview

Express is a minimalist Node.js backend framework.

---

## Security Focus

Inspect:

- Authentication
- Authorization
- JWT
- Helmet
- CORS
- Rate Limit
- SQL Injection
- Validation
- File Uploads

---

## Architecture

Inspect:

- Routes
- Controllers
- Services
- Middlewares

---

## Performance

Inspect:

- Middleware chain
- Compression
- Caching
- Async handling

---

## Common Findings

- Missing Helmet
- No validation
- Large controllers
- Missing rate limiting

---

## Recommended Practices

- Helmet
- Zod
- Express Validator
- Layered architecture
