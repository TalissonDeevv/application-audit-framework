# NestJS Audit Profile

## Overview

NestJS is an opinionated Node.js framework focused on scalability.

---

## Security Focus

Inspect:

- Guards
- Pipes
- Interceptors
- JWT
- Authentication
- Authorization
- ValidationPipe
- Secrets

---

## Architecture

Inspect:

- Modules
- Providers
- Services
- Controllers
- Dependency Injection

---

## Performance

Inspect:

- Cache
- Async providers
- Request scope
- Database queries

---

## Common Findings

- Missing ValidationPipe
- Weak Guards
- Fat Controllers
- Missing DTO validation

---

## Recommended Practices

- DTOs
- ValidationPipe
- Guards
- CQRS (when applicable)
