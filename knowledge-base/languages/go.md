# Go Audit Profile

## Overview

Go is widely used for cloud-native services and high-performance APIs.

---

## Security Focus

Inspect:

- HTTP handlers
- SQL Injection
- Goroutine leaks
- TLS configuration
- Secret handling

---

## Code Quality Focus

Evaluate:

- Error handling
- Package organization
- Interface design
- Concurrency safety

---

## Performance Focus

Inspect:

- Goroutines
- Channels
- Memory allocations
- Garbage collection

---

## Recommended Practices

- gofmt
- golangci-lint
- Context usage
- Dependency injection where appropriate
