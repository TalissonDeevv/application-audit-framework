# Python Audit Profile

## Overview

Python is widely used for APIs, automation, data science and web applications.

---

## Typical Frameworks

- Django
- Flask
- FastAPI

---

## Security Focus

Inspect:

- SQL Injection
- Pickle deserialization
- eval()
- exec()
- File uploads
- Secret management
- Command execution

---

## Code Quality Focus

Analyze:

- PEP 8 compliance
- Function size
- Cyclomatic complexity
- Exception handling
- Type hints

---

## Performance Focus

Inspect:

- Large loops
- Database queries
- Async usage
- Memory usage

---

## Dependency Focus

Inspect:

- requirements.txt
- pyproject.toml
- poetry.lock

---

## Recommended Practices

- Type hints
- Virtual environments
- Black
- Ruff
- Pydantic
