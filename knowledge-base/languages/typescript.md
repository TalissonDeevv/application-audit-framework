# TypeScript Audit Profile

## Overview

TypeScript extends JavaScript with static typing.

The auditor should evaluate whether the project effectively leverages TypeScript's safety features.

---

## Typical Environments

- Frontend
- Backend
- Node.js
- Serverless

---

## Security Focus

Inspect:

- Unsafe any usage
- Type assertions
- Runtime validation
- DTO validation
- Input validation

---

## Code Quality Focus

Evaluate:

- Strict mode
- Interface usage
- Generic types
- Type safety
- Module organization

---

## Performance Focus

Inspect:

- Generated JavaScript
- Tree shaking
- Bundle size
- Lazy loading

---

## Recommended Practices

- strict=true
- noImplicitAny
- DTO validation
- Zod
- Type-safe APIs
