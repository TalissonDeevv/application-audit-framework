# Security Cheat Sheets

The AI Audit Framework references OWASP Cheat Sheets as implementation guidance.

These documents complement security findings with practical recommendations.

## Usage

When generating recommendations:

- Prefer guidance aligned with official cheat sheets.
- Adapt recommendations to the project's technology stack.
- Avoid generic advice when framework-specific guidance exists.

---

## Rules

Recommendations should be:

- Actionable
- Technology-aware
- Evidence-based
