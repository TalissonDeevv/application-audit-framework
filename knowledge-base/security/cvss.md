# CVSS

## Overview

The Common Vulnerability Scoring System (CVSS) provides a standardized method for measuring vulnerability severity.

---

## Purpose

AAF uses CVSS as an optional severity reference.

Severity is still determined by the framework's own Severity Model.

---

## Severity Levels

Critical

High

Medium

Low

---

## Usage

CVSS should support severity decisions.

It should not replace engineering judgment.

---

## Rules

Use CVSS when enough information exists.

Do not estimate CVSS values without evidence.
