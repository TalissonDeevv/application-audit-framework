# CWE

## Overview

Common Weakness Enumeration (CWE) is a standardized classification of software weaknesses.

The AAF maps findings to CWE identifiers whenever possible.

---

## Purpose

Using CWE allows:

- Standardized reporting
- Better vulnerability classification
- Cross-tool compatibility

---

## Examples

SQL Injection

→ CWE-89

Cross-Site Scripting

→ CWE-79

Path Traversal

→ CWE-22

IDOR

→ CWE-639

SSRF

→ CWE-918

---

## Usage Rules

Always reference the most specific CWE available.

Do not assign multiple unrelated CWEs.
