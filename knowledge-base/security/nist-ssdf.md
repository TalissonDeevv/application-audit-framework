# NIST Secure Software Development Framework

## Overview

The NIST SSDF defines best practices for secure software development.

AAF uses the SSDF to evaluate development maturity.

---

## Areas

- Prepare the Organization
- Protect the Software
- Produce Secure Software
- Respond to Vulnerabilities

---

## Usage

Applicable during:

- Architecture Review
- Development Review
- DevSecOps Assessment

---

## Goal

Determine whether secure development practices are consistently applied.
