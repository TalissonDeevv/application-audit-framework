# OWASP ASVS

## Overview

The OWASP Application Security Verification Standard (ASVS) defines security verification requirements for modern applications.

The AAF uses ASVS as a verification baseline.

---

## Purpose

The ASVS is used to verify:

- Authentication
- Authorization
- Session Management
- Input Validation
- Cryptography
- Logging
- Configuration
- APIs

---

## Usage

When auditing a project:

- Verify applicable ASVS controls.
- Reference violated controls.
- Include recommendations based on ASVS.
