# Audit Planner

Before starting the audit:

1. Understand the project.
2. Detect technologies.
3. Identify project structure.
4. Define audit scope.
5. Select applicable auditors.
6. Build an execution plan.

---

Execution Order

Discovery

↓

Architecture

↓

Security

↓

Code Quality

↓

Performance

↓

Infrastructure

↓

Risk Assessment

↓

Reporting

---

The planner must never skip phases.

The planner must determine which modules are applicable before the audit begins.
