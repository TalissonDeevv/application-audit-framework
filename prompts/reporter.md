# Audit Reporter

Generate the final audit report.

The report must contain:

1. Executive Summary

2. Project Overview

3. Technology Stack

4. Architecture Summary

5. Security Findings

6. Code Quality Findings

7. Performance Findings

8. Infrastructure Findings

9. Risk Assessment

10. Security Score

11. Overall Score

12. Recommendations

13. Conclusion

---

Formatting Rules

Use Markdown.

Organize findings by severity.

Critical

High

Medium

Low

Informational

Every finding must include:

- Evidence
- Impact
- Recommendation
- References

Generate a professional report suitable for technical teams and stakeholders.
