# Report Schema

## Overview

The Report Schema defines the structure of the final audit report generated by the AI Audit Framework.

It consolidates the outputs from every auditor into a single engineering document.

---

---

# Report Requirements

Every report must include:

- Executive summary
- Technical scores
- Findings grouped by severity
- Recommendations
- Final conclusion
